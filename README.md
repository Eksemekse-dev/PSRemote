# PSRemote

Aplikacja iOS do laczenia sie z PlayStation 4/5 (Remote Play).
Silnik: chiaki-ng (do podlaczenia).
GUI: SwiftUI.

## Build lokalnie

Wymagania: macOS, Xcode 15+, XcodeGen.

make ipa

## Build w chmurze

Push na main -> GitHub Actions buduje .ipa automatycznie.
Artefakt: Actions -> ostatni run -> Artifacts -> PSRemote-unsigned-ipa.
